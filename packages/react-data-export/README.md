# react-data-export

Export data from React to `.xlsx` and `.csv`.

> **1.0 is a from-scratch rewrite in progress.** The dataset module (`exportDataset`, `exportWorkbook`, `useExcelExport`, `<ExcelExport>`) is implemented but not yet released as a 1.0 prerelease. See the [repository README](https://github.com/securedeveloper/react-data-export#readme) for status and the [API design](https://github.com/securedeveloper/react-data-export/blob/main/docs/api.md). The current stable release is **0.6.x**; its docs are at the [`v0.6.0` tag](https://github.com/securedeveloper/react-data-export/tree/v0.6.0).
